## 制作与九宫格

画面来自内置 image_gen，使用风格板和 UI 元素总图作为参考；代码仅切图、抠底、缩放、裁边、复制及制作带标签的 QA。像素精灵与 tile 使用最近邻缩放。面板、按钮、条类中央留白，文字由客户端绘制；完整建议边距见 `NINE_PATCH.json`。通用按钮左右 24px、上下 16px；常规面板四边 24px；体力条左右 10px、上下 8px。
