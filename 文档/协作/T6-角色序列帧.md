# 任务 T6：局内角色序列帧（藏者 / 猎手 / 幽灵 + 伪装特效）

工作根目录：`E:\Game_Work\AI 游戏\多人躲猫猫`。只新增下表文件，**不要改动或删除任何已有资产、代码**。

## 背景

局内角色目前是单帧贴图（`素材/UI拆分资产/00-共享资产/12-局内精灵/sprite-hider.png`、`sprite-hunter.png`、`sprite-ghost.png`，128×192），移动时只是平移。现在要做走路动画。这是第一次尝试序列帧，**帧与帧之间的一致性是验收重点**。

## 硬性要求

1. **必须用 image_gen（gpt-image-2）生成**，禁止用 PIL / 代码绘制、拼接肢体、平移像素伪造动作。PIL 只能用于抠底、切帧、对齐、缩放、检查。
2. **同一个动作的所有帧必须在同一次 image_gen 里画成一张横向序列图**（例如「4 帧一排，等宽格子，纯品红 #FF00FF 底」），再切成单帧，这样画风和比例才一致。把现有单帧贴图作为参考图输入，保持同一角色设计、配色、描边。
3. 风格：与现有 `sprite-*.png`、风格板 `素材/参考/风格板-v1.png` 一致的像素风，俯视略带 3/4 视角，深色 1–2px 描边。
4. 单帧规格：**128×192 透明画布**，角色水平居中（x=64），**脚底统一落在 y=176**，头顶约在 y=40–60。切帧后按脚底对齐（不是按包围盒居中），保证播放时不抖。
5. **藏者不戴帽子**（短发、露出头顶），睡衣为**白色 / 极浅灰**，因为客户端会用玩家颜色给睡衣着色，帽子之后由衣柜单独叠加。其他部分（肤色、头发、描边）保持原样。
6. 输出为**横向序列条**：`N 帧 × 128` 宽、192 高的 PNG（例如 4 帧 = 512×192），帧从左到右排列。
7. 自检（PIL，每条都要做）：
   - 尺寸 = 帧数×128 × 192；每帧四角 8×8 透明；无品红残留（R>200,G<60,B>200 的像素 = 0）
   - 每帧不透明像素最低行在 y=174–178（脚底对齐）
   - 同一条内各帧包围盒高度差 ≤ 10%，宽度差 ≤ 20%，不透明像素数差 ≤ 25%
   - 走路条里相邻帧不能完全相同（逐像素差异 > 3%），否则就是假动画
   不合格就重新生成整条。
