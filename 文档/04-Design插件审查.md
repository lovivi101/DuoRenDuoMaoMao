# 《熄灯》客户端 UI 审查（第 3 轮 · Design 插件）

审查方法：按 `design:design-critique` 框架（第一印象 / 可用性 / 视觉层级 / 一致性 / 无障碍），把 `素材/UI流程图/单页界面/01–19` 效果图与 `客户端/Godot_Client/docs/screenshots/01–19.png`、`live-*.png` 真实对局截图逐页对比。手机触控按约 44pt 计；1334×750 横屏在 6 英寸手机上 1pt ≈ 1px，所以可点区域至少 44×44px，正文至少 16px。13/14/16 的黑暗视野是有意设计，不算问题。`03-UI审查.md` 第 1–37 项已修复，下表只列仍能看到的问题，编号从 38 接着排。

## 总体结论

经过前两轮修复，界面框架已经基本贴近效果图：二级页的页眉、九宫格面板、黄色主按钮、头像、地图卡、结算横幅都统一了，非局内页的还原度大约在 70%。剩下的问题主要有三类：

1. **会被玩家直接看到的"穿帮"**：金币显示成 `40.0`，登录页露出开发 Mock 文案，角色整张图被染成青绿色，大立绘被截掉一半悬在半空。这几项必须修。
2. **局内 HUD 信息量不够**：小地图几乎是空的，存活头像只有 16px，事件横幅挤在角落，按钮文字压在圆环上。手机上很难一眼读懂局势。
3. **状态表达偏弱**：选中态、禁用态、开关的开/关、阵营颜色（蓝 / 红）大多只靠一点点颜色区分，层级不够明确。
