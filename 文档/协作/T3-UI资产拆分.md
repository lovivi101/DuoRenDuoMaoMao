## 做法

1. **不要从效果图裁切**（效果图有文字和叠压）。以效果图 + 风格板作为参考图，用内置 image_gen **重新生成干净组件**。
2. 批量生成：按类别做图集，每张图集 4×3 或 4×4 个组件，组件之间留足间距，放在**纯色 chroma 底**（优先 #FF00FF 品红；若组件本身含品红则用 #00FF00）。如果工具直接支持透明背景，优先用透明背景。
3. 用 Python（PIL + numpy，缺了就 `pip install numpy`）写 `素材/拆分/tools/slice_sheets.py`：连通域检测切分 → 抠 chroma（带容差 + 边缘去溢色/半透明过渡）→ 裁到内容边界并四周留 4px 透明 → 导出。脚本要可复跑。图集原图与中间文件放 `素材/拆分/sheets/`。
4. 背景（`01-背景`）与地图卡（`13-地图卡`）不需要抠图，直接生成 16:9 后 LANCZOS 缩放到 1334×750（地图卡缩放到 640×360），不透明。
5. 局内精灵（`12-局内精灵`）要**像素风俯视角 3/4 视角**，生成后用最近邻缩放到目标像素尺寸：角色 32×48 的整数倍（导出 128×192 即 4 倍），物件 32×32 的 4 倍（128×128），tile 为 **严格 32×32 无缝可平铺**（再各导出一个 128×128 预览）。`sprite-hider` 做成白/浅灰睡衣版，客户端运行时着色。
6. 面板与按钮要**九宫格友好**：四角有装饰、边框均匀、中间区域平整无图案；按钮不含文字；每个按钮若有按下态就加 `_pressed` 后缀（至少 primary/secondary/wechat 三个做按下态）。
7. 尺寸规范（导出后的像素尺寸，允许 ±10%）：图标 128×128；头像 256×256；身份徽记 256×256；道具图标 128×128（品质框同尺寸，图标能正好套进框内）；主要按钮 480×120；小按钮 240×96；圆形按钮 128×128；HUD 摇杆底 256×256、摇杆头 128×128、主按钮 200×200、技能/道具按钮 140×140；Logo 字标宽约 720；`hud-vignette-red` 为 1334×750。
