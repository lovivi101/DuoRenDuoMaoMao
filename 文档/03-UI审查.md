# 《熄灯》客户端 UI 审查（第 1–2 轮）

审查方法：参照 Anthropic Design 插件 `design-critique` 的五维框架（第一印象 / 可用性 / 视觉层级 / 一致性 / 无障碍），逐页对比 `素材/UI流程图/单页界面/*.png` 效果图与客户端实际运行截图（`客户端/Godot_Client/docs/screenshots/`）。

## 总体结论

氛围和底子是对的：夜景背景、深蓝紫配色、像素面板、局内黑暗视野、HUD 圆形按钮与摇杆都已接近效果图。但**非局内的 17 个界面还原度约 30%**：已经生成好的角色、头像、地图卡、身份徽记、奖励图标大多没用上，界面以小号纯文字 + 色块代替；主按钮的黄色贴图渲染成细条，文字看不清，这是最严重的问题。

## 做得好的地方

- 场景背景与效果图气质一致，夜色 + 暖黄灯光统一。
- 局内黑暗视野、墙体遮挡光照是玩法核心，效果到位。
- HUD 圆形按钮、摇杆、红色最终 30 秒暗角已与效果图一致。
- 像素面板边框、配色体系在全部页面保持一致。

## 第 1 轮修复结果

P0、P1、P2 全部 20 项已处理（`客户端/Godot_Client/scripts/Main.gd`、`GameHud.gd`、`GameWorld.gd`、`UiAssets.gd`）：

- 按钮 / 面板 / 输入框改用拆分资产并裁掉贴图透明留白（`UiAssets.tex_style` + `used_rect`），黄底按钮深色字，其余浅字描边；字号体系：标题 40–64（像素字体）、按钮 24–40、正文 20、辅助 16。
- 二级页统一「返回图标 + 大标题」页眉；去掉全局 Logo、标语和「☾」字符。
- 05/07/10/11/12/15/17/18/19 按效果图重做：头像、地图卡、身份卡、MVP 卡、奖励图标、好友头像与真实好友接口、三栏设置（开关/滑条/分段选择，自动保存）；08 创建房间的时长、猎手数、开关真实生效。
- HUD：存活计数框 + 头像圆点（被抓显示骷髅）、计时器框、事件横幅底板、小地图显示已探索地板与自身位置、空道具槽不写字、波纹变细并随扩散淡出、退出需二次确认。
- 修复：被抓后幽灵阵营页 0.5 秒就被切回 HUD（快照里截止时间尚为 0）。已用 `--autoplay-seek` 真实对局复验：被抓后 15 页停留 10 秒，随后回到局内幽灵视角。

验证：`scene_load` 通过、`smoke_flow` 通过、真实对局自动试玩全流程通过；逐页截图见 `客户端/Godot_Client/docs/screenshots/`。
