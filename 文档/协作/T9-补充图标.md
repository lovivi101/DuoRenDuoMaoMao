# 任务 T9：补 5 个 UI 图标

工作根目录：`E:\Game_Work\AI 游戏\多人躲猫猫`。只**新增**下面 5 个文件到 `素材/UI拆分资产/00-共享资产/05-图标/`，已有文件一律不动。

## 背景

Design 审查指出：主界面「加入房间」按钮和底栏「好友」用的是同一个图标；创建房间页设置行缺图标；局内屏幕边缘的声音提示需要一个波纹图标。

## 要产出的文件（全部 128×128 透明 PNG）

| 文件名 | 内容 |
|---|---|
| `join-room-icon.png` | 一扇半开的木门，门缝透出暖黄光，门前一把金色钥匙（表示「进入别人的房间」）；不要和 `exit-icon.png`（门 + 向外箭头）撞形 |
| `mask-icon.png` | 紫色假面舞会眼罩（卧底），金色描边 |
| `flashlight-icon.png` | 手电筒斜放，射出一束黄色光锥（猎手人数） |
| `group-icon.png` | 三个小人头像剪影并排（白色 / 浅紫），表示人数上限；和 `friends-icon.png`（三只带帽小猫头像）明显区分 |
| `ripple-icon.png` | 声波：中心一个小圆点，向外 3 道同心弧线，白色带浅黄高光，左右对称（用于屏幕边缘的「附近有声音」提示） |

## 要求

1. **必须用 image_gen（gpt-image-2）生成**，不能用代码画。PIL 只做抠底、裁切、缩放、居中、检查。
2. 风格与 `05-图标/` 里现有图标一致：像素风、深色 2px 外描边、主体约占画布 100×100 居中、少量高光，可以有 1–2 个小星点装饰。生成前先看 `friends-icon.png`、`timer-icon.png`、`robot-icon.png`、`mic-icon.png`、`exit-icon.png` 作参考。
3. 透明底，抠底后不得残留 alpha < 24 的碎像素，无品红 / 绿幕残色。
4. 自检：把 5 个新图标和 `friends-icon.png`、`exit-icon.png`、`timer-icon.png` 一起拼成一张预览（深紫底 `#28224f`，每格 128）导出到 `素材/拆分/预览/T9/icons.png`；再导出一张缩到 40px 的同排预览 `素材/拆分/预览/T9/icons-40.png`，确认小尺寸仍能认出。
5. 最终回复列出每个文件的不透明包围盒。
